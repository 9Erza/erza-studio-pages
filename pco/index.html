01 · WHAT IT DOESCO ROBI

What
it does.Co
potrafi.

A lightweight desktop tool for advanced users who want to decide which process runs on which cores, at which priority, and when. No black-box boosters.Lekkie narzędzie dla zaawansowanych użytkowników, którzy chcą sami decydować, który proces działa na których rdzeniach, z jakim priorytetem i kiedy. Bez tajemniczych boosterów.

  • 01

    Priority managementZarządzanie priorytetem

    Set a process priority from Idle to High. RealTime stays hidden behind an explicit opt-in.Ustaw priorytet procesu od Idle do High. RealTime jest ukryty za jawną zgodą.

  • 02

    Affinity and CPU SetsAffinity i CPU Sets

    Two different modes: Affinity is a hard binding, CPU Sets is a scheduling preference. PCO explains the difference instead of mixing them up.Dwa różne tryby: Affinity to twarde przypięcie, CPU Sets to preferencja planisty. PCO tłumaczy różnicę zamiast je mieszać.

  • 03

    Profiles and a watcherProfile i obserwator

    Save per-process settings (optionally bound to an exact EXE path) and let a background watcher apply them when the process starts.Zapisz ustawienia procesu (opcjonalnie dla dokładnej ścieżki EXE), a obserwator w tle zastosuje je przy starcie procesu.

  • 04

    Identity-safe changesZmiany z weryfikacją tożsamości

    Before every write PCO re-checks PID, start time, name and path. Recycled PIDs are refused, never guessed.Przed każdym zapisem PCO sprawdza PID, czas startu, nazwę i ścieżkę. Powtórnie użyte PID-y są odrzucane, nigdy zgadywane.

  • 05

    P/E-core and SMT awareRozpoznaje rdzenie P/E i SMT

    Reads the CPU topology, labels P, E and SMT threads, and says Unknown when the firmware doesn't tell it, with named core presets.Czyta topologię CPU, oznacza rdzenie P, E i wątki SMT, a gdy firmware nie podaje danych, pisze Unknown. Są nazwane układy rdzeni.

  • 06

    Session restore and telemetryPrzywracanie sesji i telemetria

    One click returns processes to their pre-optimization state. Optional CPU, GPU and RAM monitoring is off by default. The UI is in English and Polish.Jedno kliknięcie przywraca procesy do stanu sprzed optymalizacji. Opcjonalny monitor CPU, GPU i RAM jest domyślnie wyłączony. Interfejs po polsku i angielsku.

02 · GOOD TO KNOWWARTO WIEDZIEĆ

Honest
details.Uczciwie,
bez ściemy.

  • Honest limitsUczciwe ograniczenia

    The UI covers processor group 0 (the first 64 logical processors). Some changes to elevated or protected processes need administrator rights; otherwise Windows refuses and PCO reports it.Interfejs obejmuje grupę procesorów 0 (pierwsze 64 procesory logiczne). Zmiany procesów podniesionych lub chronionych mogą wymagać administratora; inaczej Windows odmawia, a PCO to zgłasza.

  • No promises on speedBez obietnic wydajności

    Gains depend on the workload and are never promised. Incorrect settings can reduce stability.Zyski zależą od obciążenia i nie są obiecywane. Nieprawidłowe ustawienia mogą pogorszyć stabilność.

  • Non-invasiveNieinwazyjnie

    No driver, service or kernel component, no memory reading and no DLL injection. Compatibility with anti-cheat isn't guaranteed; use with online games at your own risk.Bez sterownika, usługi ani komponentu jądra, bez czytania pamięci i wstrzykiwania DLL. Zgodność z anti-cheatem nie jest gwarantowana; używasz z grami online na własne ryzyko.

  • A hobby projectProjekt hobbystyczny

    Made by one person for fun, MIT licensed, provided as is. Related to FrameHub, but a separate, focused tool.Tworzony przez jedną osobę dla przyjemności, licencja MIT, bez gwarancji. Spokrewniony z FrameHub, ale osobne, wyspecjalizowane narzędzie.

Get

  1. 01Download ProcessCoreOptimizer_Setup_2.0.0.exe from GitHub Releases and compare its SHA-256 with the one in the release notes.Pobierz ProcessCoreOptimizer_Setup_2.0.0.exe ze stron wydań na GitHubie i porównaj jego SHA-256 z podanym w notatkach wydania.

Aktualizacja z wersji 1.3.0 wymaga najpierw odinstalowania jej (profile zostają w %APPDATA%\ProcessCoreOptimizer).
