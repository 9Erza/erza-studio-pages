03 · AFFINITY VS CPU SETS

Two modes,
not synonyms.Dwa tryby,
nie synonimy.

Affinity

HowJak
A hard binding: the process may run only on the selected logical processors.Twarde przypięcie: proces może działać tylko na wybranych procesorach logicznych.
Good forDo czego
Strict isolation and repeatable pinning tests.Ścisła izolacja i powtarzalne testy przypięcia.
Watch outUwaga
Pinning too narrowly can lower throughput.Zbyt wąskie przypięcie może obniżyć wydajność.

CPU Sets

HowJak
A scheduling preference: Windows prefers the selected processors but may schedule elsewhere under load.Preferencja planisty: Windows woli wybrane procesory, ale pod obciążeniem może użyć innych.
Good forDo czego
Everyday steering on hybrid CPUs, friendlier to the Windows scheduler.Codzienne kierowanie na procesorach hybrydowych, przyjaźniejsze dla planisty Windows.
Watch outUwaga
A weaker guarantee by design.Z założenia słabsza gwarancja.

A restricted affinity mask also limits what CPU Sets can do for that process. Since 2.1, applying CPU Sets widens a stale hard affinity instead of silently fighting it.Zawężona maska affinity ogranicza też działanie CPU Sets dla tego procesu. Od wersji 2.1 zastosowanie CPU Sets poszerza starą twardą affinity zamiast po cichu z nią walczyć.

04 · GOOD TO KNOWWARTO WIEDZIEĆ

Honest
details.Uczciwie,
bez ściemy.

  • Identity-safe changesZmiany z weryfikacją tożsamości

    Before every write PCO re-checks PID, start time, name and path. Recycled PIDs are refused, never guessed.Przed każdym zapisem PCO sprawdza PID, czas startu, nazwę i ścieżkę. Powtórnie użyte PID-y są odrzucane, nigdy zgadywane.

  • Non-invasiveNieinwazyjnie

    No driver, service or kernel component, no memory reading and no DLL injection. Compatibility with anti-cheat isn't guaranteed; use with online games at your own risk.Bez sterownika, usługi ani komponentu jądra, bez czytania pamięci i wstrzykiwania DLL. Zgodność z anty-cheatem nie jest gwarantowana; z grami online używasz na własne ryzyko.

  • No promises on speedBez obietnic wydajności

    Gains depend on the workload and are never promised. Incorrect settings can reduce stability.Zyski zależą od obciążenia i nie są obiecywane. Nieprawidłowe ustawienia mogą pogorszyć stabilność.

  • Honest limitsUczciwe ograniczenia

    The UI covers processor group 0 (the first 64 logical processors). Changes to elevated or protected processes may need administrator rights; otherwise Windows refuses and PCO reports it.Interfejs obejmuje grupę procesorów 0 (pierwsze 64 procesory logiczne). Zmiany procesów podniesionych lub chronionych mogą wymagać administratora; inaczej Windows odmawia, a PCO to zgłasza.
